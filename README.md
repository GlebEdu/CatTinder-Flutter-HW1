# Кототиндер

![Кототиндер](screenshots/start.jpg)

Tinder-подобное приложение для знакомства с породами кошек. Проводите вправо, чтобы лайкнуть котика, влево — чтобы пропустить. Узнавайте интересные факты о разных породах!


## Реализованные фичи

- **Онбординг** — показ при первом запуске 
- **Регистрация / Вход** — локальная регистрация и вход с сохранением состояния в secure storage
- **Главный экран со случайными котиками** — каждый раз новая порода
- **Свайп-интерфейс** как в Tinder:
  - Свайп вправо/влево или кнопки для лайка/дизлайка
  - Визуальные индикаторы направления
  - Анимации при свайпе
- **Счетчик лайков** — отслеживайте понравившихся котиков
- **Детальная информация о породах**:
  - Полное описание породы
  - Характер, происхождение, продолжительность жизни
  - Рейтинги адаптивности и интеллекта (звезды 1-5)
- **Список всех пород** с краткой информацией
- **Навигация** через BottomNavigationBar
- **Кнопка выхода** - сделана для тестирования повтороного входа 

**Архитектура / DI:** слоистая структура (data / domain / presentation), зависимости собираются через GetIt. 

**Тесты:** 
- **Unit-тесты:** тесты для логики аутентификации (signUp/login).
- **Widget-тесты:** тесты для экрана входа (валидация и успешный сценарий).

## Установка и запуск

### Предварительные требования
- Flutter SDK (версия 3.0.0 или выше)
- Android Studio / VS Code
- Эмулятор Android или физическое устройство

### Шаги установки
```bash
# 1. Клонируйте репозиторий
git clone https://github.com/GlebEdu/CatTinder-Flutter-HW1.git

# 2. Перейдите в папку проекта и создайте .env в корне проекта  с ключом
CAT_API_KEY=your_key_here

# 3. Установите зависимости
flutter pub get

# 4. Запустите приложение
flutter run

# Запуск тестов:
flutter run
```

### Использование ключа 
Приложение использует TheCatAPI.

Получить свой ключ можно на [thecatapi.com](https://thecatapi.com/signup).

### Конфигурация API-ключа

Приложение читает ключ из файла `.env` — не храните ключи в репозитории.

1. Создайте файл `.env` в корне проекта и добавьте:

```
CAT_API_KEY=your_key_here
```

2. Установите зависимость и обновите пакеты:

```bash
flutter pub add flutter_dotenv
flutter pub get
```

3. Запуск приложения:

```bash
flutter run
```


## Технологии

- **Flutter** 3.0+ — кросс-платформенная разработка
- **Dart** — язык программирования
- **http** — работа с API
- **cached_network_image** — кэширование изображений
- **equatable** — сравнение объектов
- **get_it**  — простой DI/сервис-локатор для управления зависимостями
- **flutter_secure_storage**  — безопасное локальное хранение 
- **flutter_dotenv**  — загрузка API-ключа из .env (API-ключ)
